## 当前质量门槛

现有 69 项回归通过不意味着游戏规则完整。它验证已有分享码兼容、输入消毒、候选限制、预算区间、触发去重、部分确定生产、调阵不变性和解释一致性。没有实战胜率标注，不能声明推荐质量已达到稳定最优。

下一轮算法变更应先附：当前赛季证据 → 规则解释 → 需要的新输入 → 真实局面案例 → 实现与验证。没有足够证据的发牌概率/无限期收益不写入排序。
