# 局内推荐规则与边界

本次按仓库 V3_1 的「卫戍协议·规程·序列Ⅰ」数据迭代（2026-11-14）。推荐分数是可解释的启发式，不是胜率，也不等于覆盖了全部战斗规则。

## 已纳入排序

- 原有主盟约目标、激活/强化损失、禁用池、经济盟约整备区计数、同名不重复计数。
- 可选回合、资金、盟约层数快照。留空未知，显式 0 保留；旧存档自动兼容，撤销深复制。
- 明确获得时固定叠层、免费刷新、装备奖励；矩按调度中心等级。晋升只用精锐获得特质，不重复计第三张普通卡。投资人按购入前激活状态估计倍率。
- 明确休整结束生产、允许整备区生效的生产、条件战斗叠层潜力、已录层数转属性、乌萨斯保存临时层。未来生产有限展望，晚期降低生产权重；条件上限不称为实得。
- 换人比较整队边际收益，并保留换下位精锐、装备、持续生产的机会成本。
- 部分可表达的策略整队档位：阿米娅场上盟约种类、Touch 两精锐门槛、罗素/陈精锐投入、华法琳等阶覆盖、铃兰获得能力/苏苏洛休整能力。具体权重是启发式，不是属性数值。
- 已知资金不足降序；远见已录层数减价、休露丝首购状态未知提示、坎诺特跌破 5 资金代价。普通策略不假定跨回合利息。

## 仍未建模

同名多个精锐、商店刷新历史/牌库概率、极光与忍冬成长次数、主动技能是否已使用、出售循环、部署站位、技能施放/敌方/伤害模拟、领袖指令及全部装备交互未完整建模。所有策略仍可选择，但未列出的策略主要保留原有方向匹配。部分带复杂条件的特质不赋值而不是编造收益；不能保证最优阵容。

资金/层数不自动变动，玩家需更新快照。推荐不会自动购买、换人或把奖励装备假定已装备。已有精锐后的经济复购目前仍不推荐，需人工判断。远见历史曾达减价门槛但层数后来改变时，请按实际商店价核对。

## 第二轮：对局操作与确定性规则修正

- 增加「先看整备区」免费上场建议，保留原持有装备；每条为独立方案，不触发买入/晋升收益，应用后可撤销。
- 预算独立于收益分：不够最低可能价即资金不足；介于未知折扣区间标为待核价，不能把未知远见折扣当成免费。坎诺特末轮不再扣下一回合收入机会成本。
- 推荐详情展示可加总的阵容、持续收益/投入、获得、收集、经济贡献；适配仅同分参考。不够钱的候选排后，但可手动记录确实获得的奖励牌。
- 装备获得识别数量与完整名称，凯瑟琳随机升级奖励不作为确定收入。
- 寒檀计休整开始/结束但不倒算已过去的本轮开始。涤火杰西卡按装备携带者而非装备件数，维娜按不同阶，焰尾按已记录整备人数估计。
- 未知价格仍请核对游戏；省略未记录复制体数量的局面可能低估整备人数收益。没有借此声称具备完整伤害/站位模拟。
